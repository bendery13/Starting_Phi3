# Web Scrapping User Reviews
&emsp; This program is designed to pull user reviews from an online commerce website and present them neatly into a text file. It is part of a larger project that will integrate Microsoft's Phi-3 model to help analyze the reviews. This program pulls user reviews from Google Pixel smartphone models 4, 5, 6, 7, and 8 from eBay, cleans the data using the Python package Beautiful Soup, and then posts each phone's reviews in their respective output files. Each model has its own output file which contains every current review from the phone's respective eBay listing. 

## Installing the Web Scrapper
&emsp; To use this program, you have two options for setting up your environment. First, you can create a virtual environment from the connected requirements.yaml file. Importing this file into a virtual environment will install all the necessary dependencies for running the program. You can do this by entering  __conda create --name my_yaml_env --file requirements.yaml__ into a command line. This command will create a virtual environment named 'my_yaml_env' - you can change the name of it by editing the prompt above. Once the virtual environment is created, you should be ready to run the program.

&emsp; Second, if the YAML file does not work or you do not have conda installed on your machine, you can also follow the steps below to manually install the necessary packages for the program. These steps will guide you through downloading Beautiful Soup, LXML, and requests to your Python environment. Once you install all three packages, you are ready to use the software.


### Installing Python Packages
&emsp; There are three packages necessary for running the Web Scrapper program. If you already have them installed, you are ready to use the scrapper. If you do not, I will guide you through preparing your machine to run the scrapper. First, you will need to install Beautiful Soup, which is the HTML parser that is used in this program. This packages allows the HTML code from the website to be cleaned and looked through. It then lets us pick which parts of the website we want to see. In this case, the user reviews for the Google Pixel devices are what is being parsed from the website. Next is the LXML package which allows the machine to process the HTML from the website. These two packages work together to get the end result we are looking for. To install these packages, enter the following commands into a command line: __pip install beautifulsoup4__ and __pip install lxml__. Your machine will read the packages from the web and install them onto your local machine. The final package needed to run this program is python-requests. This package allows us to harvest the website's contents by using the GET function on the website's URL. You can install this package using this command: __pip install requests__.

## Using the Web Scrapper
&emsp; This web scrapper allows a user to easily read the reviews for Google Pixel smartphones on eBay. It is designed by looking at the HTML tags of the website code and pulling the contents from the review's title and body. Using the software is extremely simple since no user input is needed on the program's side. To use the software, simply download all of the text files connected to this repository and make sure they are in the same folder as the Python file. Next, make sure that all of the required Python packages have been installed. Once both of these tasks are complete, you are ready to use the program. Just click the run button on the Python code, and the scrapper will pull all current reviews from the URLs in 'websites.txt'. Since the inputs always come from the same text file, the output will be the same every time until a new review is added to eBay. Additionally, since eBay's HTML skeleton should have the same structure across the whole website, you can try changing the 'websites.txt' file by adding your own URLs.
